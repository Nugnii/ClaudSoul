# name-consumer-notice

**Назначение.** Правка, после которой файл перестаёт читать переменную окружения, называет файлы, которые эту
переменную ещё задают и зовут правленый файл, — до коммита, пока переименование не разошлось с потребителями.

**Событие.** `PreToolUse[Write|Edit|MultiEdit]`; путь команды (`sed -i`, heredoc) — подачей диспетчера
`bash-write-dispatch.sh` (строка `GUARDS`). Уровень подсказки (`additionalContext`).

**Файлы.**
- `hooks/name-consumer-notice.sh` — хук: повод, признак, точность, пределы в шапке;
- `hooks/lib/name_consumers.py` — разбор: новая редакция файла, снятые чтения, потребители;
- `hooks/tests/test_name_consumer_notice.sh` — 32 ноги, обе стороны различения; каждое условие признака держит
  своя нога: 23 мутанта, снимающих по одному условию, краснят каждый свою; ноги T16–T18 — три состояния прибора
  (сломанный разбор, непрочитанный потребитель — `git grep` называет его только в потоке ошибок при коде 0,
  неразборный вход) говорят, а не молчат;
- `hooks/tests/fixtures/probe_D1200.sh` — проба пункта: повод 31 октября 2026 в песочном дереве со вторым читателем
  имени (как `backlog-archive.sh` в живом дереве), неучтённый потребитель, законное подключение, правка командой и
  коммит той же командой.

**Признак.** Прежняя редакция файла читает переменную в строке кода (не в комментарии, не в докстроке): `$NAME`,
`${NAME…}`, `os.environ.get/[ ]`, `getenv`, awk `ENVIRON[…]`, `'NAME' in os.environ`, а в файле, трогающем окружение,
и голый литерал (чтение через обёртку `_int("NAME", 300)`). Новая редакция не читает его ни сама, ни по префиксу
(`startswith("GIT_")`), ни через файл, который подключает строкой кода без прозы (одноимённый — только если в той же
строке назван и его каталог). Потребитель — другой `*.sh`/`*.py` дерева, учтённый или новый неучтённый, который в
строке кода задаёт переменную (`NAME=…`, `'NAME': …`, `["NAME"] = …`, `setenv/putenv/setdefault('NAME'`) и называет
правленый файл. «Было» — последний коммит; если он уже равен новой редакции (правка и коммит одной командой), —
родитель свежего, не старше 600 с, коммита.

**Точность.** Замер 3 ноября 2026 ядром `consumers()` по 2 591 коммиту: 3 срабатывания в двух правках, настоящие обе
(повод b6f66dbc и `test_root_cause_lib.sh`, задающий `DPR_BACKLOG`, `DPR_LESSONS`, которых
`declared-problem-recorded.sh` не читает с 12 сентября 2026, — D1241). Без уточнения про подключение — 16 в 13 правках,
13 ложных. Функции не взяты: 17 из 17 снятых определений с живыми вызовами — перенос в другую библиотеку.

**Пределы.** Транзитивный потребитель (зовёт драйвер, который зовёт файл) не виден; «было» берётся из коммита, а
рабочая копия общая — незакоммиченное снятие соседней сессии приписывается текущей правке; ключ состояния и имена
без подчёркивания не судятся.

**Зависимости.** git — через `project_git` (`hooks/paths-lib.sh`, D515); python3, jq. Нет библиотеки или разбора —
хук молчит («инструмента здесь нет»); разбор упал — хук говорит, что потребители НЕ ПРОВЕРЕНЫ.

**Соседи.** `undefined-function-check.sh` — вызов несуществующей функции в записанном файле (обратное направление);
`impact-inject.sh` — кто стоит на файле по карте связей (единица — файл, здесь — имя).
