# test-exit-explicit-guard — тест в старой форме кода возврата не записывается

**Назначение.** Отказ в момент записи `hooks/tests/test_*.sh`, если итог правки кончается не явным `exit`: код возврата теста возьмётся у последней команды, и любая дописанная строка сделает прогон зелёным при красных утверждениях.

**Файлы.** `hooks/test-exit-explicit-guard.sh` (PreToolUse на Write|Edit|MultiEdit; регистрация — `install.sh`), предикат — `hooks/tests/test_tests_exit_explicit.sh` (принимает явные аргументы-файлы; без аргументов — весь индекс git), тест `hooks/tests/test_test_exit_explicit_guard.sh` (10 проверок).

**Зависимости.** jq, python3 (сборка итога правки: Write — целиком, Edit — замена старой половины новой с уважением `replace_all`, MultiEdit — по очереди), предикат в том же дереве, что правимый файл: корень берётся у пути файла, а не у сессии.

**Правила.**
- Правило одно и живёт у `test_tests_exit_explicit.sh`; страж зовёт его на собранном итоге с явным аргументом, копии предиката нет (род K). Изменится правило — изменится и отказ.
- Уровень — отказ (`permissionDecision: deny`). Признак с одним последствием; точность измерена при заведении 12 сентября 2026: предикат по всем тестам дерева (440) — 0 срабатываний, положительный контроль — старая форма в T1/T3/T6, настоящий тест дерева как Write — тишина (T9).
- Молчит: файл вне `hooks/tests/test_*.sh`; дерево без предиката (гейт `-f` до вызова — чужой проект, прибора нет); старая половина правки в файле не найдена (итог неизвестен, отказ назовёт сам инструмент); предикат упал не по форме концовки (нет строки «FAIL: код возврата» — «не измерено», а не дефект).

**Повод (D338).** D289 привёл 232 теста из 349 к явному `exit`, и в тот же день новый тест (`test_mcp_orphan_reap.sh`) был написан в старой форме — поймал полный прогон через час. Проверка, оформленная тестом, судит сборку, а не запись (`case-2026-09-07-check-shaped-as-test-does-not-guard`); каждый новый тест пишется по образцу соседа и воспроизводит его концовку, и без стража в момент записи счётчик отрастает обратно за несколько дней (замер D289: 220 → 232).
