# Модуль: bash-write-dispatch (правка командой доходит до стражей записи)

**Назначение.** Предмет «запись в файл» достижим двумя путями: инструментом
(`Edit`/`Write`/`MultiEdit`) и командой (`python3 - <<PY`, `sed -i`, перенаправление).
Стражи записи подписаны на первый. Диспетчер на `PostToolUse[Bash]` подаёт им правку,
сделанную вторым путём, — синтетическим событием `Write` с телом файла.

**Файлы.**
| Файл | Роль |
|---|---|
| `hooks/bash-write-dispatch.sh` | диспетчер: изменённые файлы берутся у гита, подаются стражам из объявленного списка |
| `hooks/tests/test_bash_write_dispatch.sh` | свидетель, 7 ног: положительный контроль, протокол подачи, названная цена, дедуп, чистый файл, чужое событие, отсутствие стража |

**Зависимости.** jq, git; стражи из списка — `secret-guard.sh`, `test-exit-explicit-guard.sh`,
`backlog-open-write-guard.sh` (отказы уровня 4) и `pipefail-grep-q-notice.sh` (замечание,
добавлено по замеру: 0 срабатываний на 719 отслеживаемых `*.sh`, то есть говорит только на
новом нарушении).

**Двое добавлены после СНЯТИЯ возражений** (не вопреки им): `test-cost-notice` взял меру,
источник и реестр у владельца факта (D410), `backlog-touch-check` перестал терять слот
дросселя, когда подача сузилась до тронутого с прошлого события. Слепых к Bash — 0,
покрыто диспетчером 6, цена хода 0,5 с.

**Кого НЕ подаём и почему — замером, а не соображением** (13 сентября 2026, D407):
| Страж | Отказ | Число |
|---|---|---|
| `budget-gate` | предмет не файл | из входа только `session_id` и `tool_name`; вывод побайтово одинаков на чистом и нарушающем |
| `module-context-inject` | нем по построению в этом дереве | индекса модулей нет; условие снятия записано в самом страже |
| `backlog-touch-check` | подача ГАСИТ рабочий путь | его дроссель на сессию с общим журналом: задним числом → настоящая правка того же файла даёт 0 байт против 669 в свежей сессии; попадание на каждый третий тронутый файл |
| `test-cost-notice` | мера не та | судит по стенным секундам, владелец факта — по процессорным (D410: 16 против 10, шесть ложных) |

**Повод и замер (13 сентября 2026, D407).** За сессию правлено 11 файлов кода, сработал НОЛЬ
стражей записи; у `backlog-open-write-guard` — ноль срабатываний при четырёх коммитах,
тронувших его предмет. Доля правок оболочкой измерена 27 августа: 1357 против 1675 (45%).

**Правила.**
- **Честно названная цена:** событие ПОСЛЕ записи, поэтому отказ здесь невозможен по
  построению. Уровень 4 на этом пути вырождается в громкое уведомление «почини или откати»;
  на пути инструмента отказ остаётся живым.
- Список стражей объявлен в самом диспетчере: страж добавляется строкой, а не новым
  механизмом — иначе у одного устройства появилось бы восемь мест для расхождения (R1).
- **Два ограничителя, и порядок их применения объявлен**: дедуп гасит ПОКАЗАННОЕ (пара
  «файл + страж» за сессию), потолок печати (`BASH_DISPATCH_MAX_SHOW`, по умолчанию 5)
  и бюджет вызовов (`BASH_DISPATCH_MAX_RUNS`, 6) ОТКЛАДЫВАЮТ показ на следующее событие.
  Отложенная пара флага не получает — иначе обещание «ждут следующего хода» было бы ложью
  (первая редакция ставила флаг до потолка; дробь класса 1 из 4 мест дерева).
- **Подаётся ТРОНУТОЕ С ПРОШЛОГО СОБЫТИЯ, а не весь грязный список.** Метка сессии
  (`bash-dispatch-mark-<sid>`) двигается на каждом событии; отложенные пары держит очередь
  (`bash-dispatch-queue-<sid>`), иначе перенос ломается — мгновенный снимок и отсрочка
  спорят по построению. Первое событие сессии берёт тронутое за последние пять минут.
- **Цена измерена:** 0,12 с на вызов стража; бюджет держит ход в 0,88 с вместо ~9 с при
  восьми стражах и десятке тронутых файлов. Файлы дороже 400 КБ пропускаются.
- **Потолок знаков сообщения ИЗМЕРЕН, а не взят круглым** (14 сентября 2026): сообщения
  стражей доходят до 590 знаков, и прежние 400 отрезали у `backlog-touch-check` ТРЕТИЙ
  исход — «пункт уже решён, а метка осталась, закрой с показанием», — ровно тот, что после
  записи вероятнее прочих. Круглое число резало по самому нужному концу.
