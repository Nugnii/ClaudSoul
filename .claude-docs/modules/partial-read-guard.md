# Модуль: страж неполного чтения (partial-read-guard)

**Назначение.** Называть числом, какая часть файла реально прочитана, чтобы утверждение об ОТСУТСТВИИ чего-либо в файле не делалось по прочтению начала. Механизирует правило «Итог правки: что изменилось И что не менялось» (глобальный CLAUDE.md), у которого текстовой формы недостаточно: инструмент Read без параметров молча обрезает файл на 2000 строк, и неполнота изнутри невидима.

**Файлы.** `hooks/partial-read-guard.sh` (PostToolUse[Read], инжект additionalContext).

**Зависимости.** `jq`; `wc`/`tail` для счёта строк; `$STATE_DIR` для файла `partial-read-<sid>.seen`. Порог умолчания Read — `READ_DEFAULT_LIMIT` (2000).

**Правила.** Молчит при полном чтении, на не-Read инструментах, на картинках/PDF/блокнотах и при повторном чтении того же файла в той же сессии (иначе разбор большого файла кусками даёт фон). Потолок назван в шапке скрипта: чтение через Bash (`cat`, `sed`, `head`) хук не видит, там правило держится на агенте.
