# commit-condition-notice — коммит без своего условия называется с адресом

**Назначение.** Подсказка на `PreToolUse[Bash]` о двух формах одного знания (`pattern-commit-condition-lives-in-the-command`):

1. **Коммит прошлого пакета ушёл без правки своего пакета.** В пакете параллельных вызовов (одно сообщение модели, один `message.id` в расшифровке) раньше `git commit` стоит правка файла того же репозитория — `Edit`, `Write`, `MultiEdit`, `NotebookEdit`, — её результат вернулся ошибкой (привязка устарела, файл не прочитан, страж отбил), а коммит прошёл. На ближайшем вызове `Bash` подсказка называет коммит (`tool_use_id`), файл и первую строку причины и предлагает дополнить коммит (`git commit --amend` до push либо следующим коммитом). О каждом коммите — один раз.
2. **Нынешняя команда коммитит после шага через `;` или перевод строки.** Если код шага — условие коммита (`git add`/`rm`/`checkout`/…, `cd`, интерпретатор, набор, `sed`), подсказка называет шаг: коммит исполнится и при упавшем шаге.

**Молчит:** правка легла; правка вне репозитория коммита (корни сверяются `project_git`, вложенный репозиторий — другой); коммит вернулся ошибкой; правка в другом пакете или после коммита; о коммите уже сказано; шаг перед коммитом — вывод (`echo`, `cat`, `git status` …), стоит под `&&`, `then` или `set -e`; текст в теле heredoc. Сломанный разбор (исключение питона, старый `write_targets.py`) сказан подсказкой, а не промолчан.

**Почему подсказка, а не отказ.** Замер 15 ноября 2026 (D1298): пакет пишется в расшифровку ПОСЛЕ хуков своих вызовов — в сессии с зондом на `PreToolUse[Bash]` своего `tool_use_id` в файле нет, а правка пакета и её отказ лежат дальше его конца; правка, не прошедшая проверку харнесса («строка не найдена»), не зовёт ни одного хука. До коммита его пакет не виден никому, поэтому первая редакция (отказ коммиту своего пакета, `batch-failed-edit-commit-guard`) была в мире слепа. Вторая форма — признак со смешанным исходом: коммит ломается, только если шаг упал.

**Файлы.** `hooks/commit-condition-notice.sh` (регистрация — `install.sh`), свидетель `hooks/tests/test_commit_condition_notice.sh` (18 ног; 15 мутантов — без проверки пакета, без признака ошибки правки, без границы пакета, без порядка, без сверки корней, без отметки, без исключения субагента, без признака ошибки коммита, любой шаг, любой разделитель, без `set -e`, без `then`, молчащий разбор, без поиска живого каталога, без проверки шага — каждый роняет свою ногу).

**Зависимости.** `jq`, `python3`, `git`; владельцы фактов: «это коммит» — `hooks/command-scope-lib.sh` (`is_git_commit`), разбор команды, разделители и каталог коммита — `hooks/lib/write_targets.py` (`git_calls`, `_shell_words_text`, `_is_sep`), текст результата — `hooks/lib/deny_mark.py` (`result_text`), git — `project_git` (`hooks/paths-lib.sh`). Отметки — `state/commit-condition-notice-<sid>-<cksum>`.

**Чем решалось раньше.** Знание держалось текстом. Соседи по знанию держат другие условия коммита: ветку — `denied-branch-commit-guard` (отказ), состав индекса — `git-add-sweep-guard` (отказ), набор по изменённым — `affected-tests-reminder` (подсказка).

**Замер (15 ноября 2026).** По расшифровкам всех проектов: коммитов после непрошедшей правки своего пакета — 18 (пересчёт скептика предикатом стража), из них 13 — после отказа стража на правке, 5 — после «строка не найдена»; среди них D1248. Форма «шаг; коммит» — 232 коммита из 5 829, из них 93 после шага-условия. Живая нога: сессия `claude -p` без пользовательских настроек с этим хуком — пакет «непрошедшая правка + коммит», затем `git log`: подсказка пришла модели с номером коммита и файлом. Цена — 0,08–0,09 с на вызов при нагрузке 12,8, на расшифровке 630 МБ (хвост читается байтами с конца, `CCN_TAIL_BYTES`, 4 МБ).

**Названные пределы.** Вызов субагента о прошлых пакетах молчит: его `transcript_path` — расшифровка родителя (D449), подсказка ушла бы не тому. Ход, кончившийся пакетом коммита, услышит подсказку на первом `Bash` следующего хода. Запись оболочкой в пакете (heredoc, `sed`) не судится — у её провала нет признака «правка». «No changes to make» считается непрошедшей правкой (частота 0 в корпусе).

**Повод.** D1298 (15 ноября 2026, скептик opus по D1295 и D1297, H1): знание простояло в очереди «знание → инструмент» 27 дней при сроке 30; круг скептика по первой редакции — H: страж слеп в мире.
