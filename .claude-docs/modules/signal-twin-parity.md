# signal-twin-parity — признак видит запись в код, чем бы она ни была сделана

**Назначение.** Подаёт признаку настоящую запись файла через `python3 - <<EOF` — обеими измеренными формами вызова, `open(path,"w")` и `path.write_text(...)`, — и смотрит, опознан ли дефект. Чистая запись обязана остаться без срабатывания.

**Файлы.** `scripts/signal-twin-parity.sh`, свидетель `hooks/tests/test_signal_twin_parity.sh` (7 ног). Потребитель — строка «Проверка» пункта D415.

**Зависимости.** `hooks/detection-signals-lib.sh` — ВЛАДЕЛЕЦ и разбора признаков, и разбора «куда пишет heredoc» (`ds_heredoc_writes`); своей копии разбора здесь нет. `python3`, `jq`.

**Правила.**
- **Судится ПОВЕДЕНИЕ, а не текст.** Счёт форм по тексту знания эту дыру не ловит: при заведении пункта D415 правка руками сломала JSON признаков кавычкой внутри строки — блокер знания замолк целиком, а счёт по `awk` остался зелёным. Поэтому отдельной веткой стоит предикат «разбор состоялся», дающий отказ (код 2), а не ноль.
- **Образец собирается из частей.** Записать дефект литералом в файл под `scripts/` нельзя: живой блокер отказывает такой записи — проверено на себе в час заведения.

**Названный предел.** Судится питон внутри heredoc — обеими измеренными формами вызова записи (`open` с режимом записи: 1615 команд корпуса, `write_text`: 1817). Прочие способы (`tee` в цикле, `ed`, `printf`) прибором не покрыты. Условие снятия: замер назовёт следующий способ числом — его образец добавляется сюда же.

**Повод (D415, закрыт 15 сентября 2026).** Признак узнавал запись по ЦЕЛИ heredoc. У записи питоном цель — стандартный вход питона, путь лежит в ТЕЛЕ, и предикат цели не совпадал по построению; молчание при состоявшейся записи было неотличимо от молчания на чистой команде (корень R6), а на предикате стоят два признака уровня отказа.

**Как устроено сейчас.** У heredoc без цели перенаправления разбирается ТЕЛО, и путь берётся только из аргумента вызова записи — литералом либо через одношаговую переменную. Правило «любой путь из тела» отвергнуто замером: 2372 команды корпуса из 3715 поминают путь, в который не пишут. Замер по корпусу 15 сентября 2026: целей вида `hooks|scripts/*.sh|bash|py` видно 2071 против 259 прежде, потерянных ноль; из 2202 целей 2201 подтверждена вызовом записи независимой второй реализацией, а единственная оставшаяся принадлежит СТАРОМУ правилу (перенаправление внутри строки-фикстуры) и была там до правки.
