# guarantee-map-guard — правка по находке скептика только после карты гарантий с прогоном

**Назначение.** Отказ в момент правки файла, чей адрес назван находкой скептика у пункта долга в работе (◐) защитного слоя, пока в блоке пункта ПОСЛЕ этой находки нет абзаца «**Карта гарантий.**» с тем же адресом, словом «прогон» и командой в обратных кавычках. Правка по находке, проверенная только ногой из текста находки, ломает то, что изменённый код уже гарантировал соседям; карта перечисляет эти гарантии до правки, прогон крайнего входа проверяет поведение, а не перечень.

**Файлы.** `hooks/guarantee-map-guard.sh` (PreToolUse на Write|Edit|MultiEdit; регистрация — `install.sh`; путь оболочки — строка в `GUARDS` диспетчера `hooks/bash-write-dispatch.sh`, там отказ вырождается в уведомление), признак защитного слоя — `backlog_names_guard_layer` в `hooks/backlog-lib.sh` (вынесен из `backlog_needs_skeptic`, у признака один владелец), тест `hooks/tests/test_guarantee_map_guard.sh`, проба пункта — `hooks/tests/fixtures/probe_D1158.sh`.

**Зависимости.** jq, python3 (разбор абзацев блока и адресов), `hooks/backlog-lib.sh` того же каталога: `backlog_open_items` (пункты ◐), `backlog_item_block` (блок пункта), `backlog_names_guard_layer` (защитный слой). Без любой из трёх функций — старая редакция библиотеки — страж молчит: судить нечем; источник смеси редакций чинит D1166.

**Правила.**
- Проект — ближайший предок файла с `BACKLOG.md`; адрес — путь, извлечённый из текста целиком (D1169): `./` и `..` сведены, регистр не различается, абсолютный путь — по корню проекта; голое имя файла — тоже адрес (с расширением — без регистра, без расширения — точно: `version` не `VERSION`); имя без расширения — точное, с учётом регистра, с `_` или `-` («`probe_D1148` — чинить здесь») либо целиком из прописных латинских букв не короче трёх (`CHANGELOG`, `META`, `README`); цифра адресом не делает (`R6` — код корня), строчное однословное (`discovery`) — не адрес; слева `$` или `${` — переменная оболочки (`$README`), а не файл; голая `{` — список путей. Путь установленной копии `~/.claude/hooks/x.sh` адресом `hooks/x.sh` не считается.
- Пункты ◐ отбираются сравнением метки под `LC_ALL=C`: `awk` macOS в UTF-8-локали, отличной от C, считает «☐» равной «◐» (скептик третьего круга, H1).
- Путь оболочки: страж четвёртый в `GUARDS` диспетчера, за тремя отказами, — у файла кода он говорит на событии самой правки при потолке 6 подач; отказать там нельзя, это уведомление.
- Находка — абзац блока от метки до следующей метки (D1169: пустая строка и забор кода абзац не рвут; метка — `**…**` в начале строки, пунктом списка — только с ролью, подзаголовок — без отступа; разбор по сырым строкам блока из одной стабильной копии бэклога на весь прогон), чья метка называет отчёт круга — «скептик», «противник», «прожарка» в любом регистре: отчёт круга и перенесённая находка «Повод (… скептик …)». «Карта гарантий…» — всегда карта, даже со «скептиком» в метке; регистр метки и слова «прогон» не важен; команда-заглушка `<команда>` — не прогон. Решение владельца — находка любая, у пункта в работе.
- Карта засчитывается, только если стоит ПОСЛЕ последней находки, называющей файл: карта прошлого круга новую находку не покрывает.
- Уровень — отказ (`permissionDecision: deny`), решение владельца после /retro D1158; прогон в карте — решение владельца 28 октября 2026 по замеру D1158 (карта по чтению кода удержала D1150, но не D1153). Страж судит форму прогона; исполнялся ли он, судит скептик.
- Молчит: BACKLOG.md и его архив в любом регистре имени (иначе карту не записать); проект без `BACKLOG.md` в предках; корень без каталога `hooks/`; пункты не в работе; относительный путь во входе.
- Названные пределы: часть пути (`lib/x.py` при `hooks/lib/x.py`) адресом не считается; одноимённые файлы разных каталогов голым именем судятся оба, как и файлы с общим именем без расширения; на файловой системе с различием регистра `hooks/X.sh` и `hooks/x.sh` приравнены; файл-пример в отчёте требует карты (в том числе README.md по «Поводу» самого D1169); путь через `~/` или переменную (`$R/hooks/x.sh`) — не адрес; бэклог, переписываемый фоновым писателем во время правки, может отдать пустой блок — пропуск; очередь, потолки и перечень расширений диспетчера — его пределы (D1169).

**Повод (D1158).** /retro 27 октября 2026 по вопросу владельца «сами вносили регрессии — это признак чего?»: 6 регрессов H в 5 из 7 коммитов, судимых скептиком opus, и седьмой в пятом круге D1150. Урок «зависимости корня — чек-лист регрессии» стоял текстом в доктрине, памяти и знании и подсказкой `impact-inject` — не сработал ни один уровень.
