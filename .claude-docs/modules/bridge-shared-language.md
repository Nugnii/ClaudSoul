# Модуль: совместный язык (мост L3↔L7)

**Назначение.** Предлагать кандидатов в shared vocabulary из речи собеседника; словарь курирует человек.

**Файлы.** `hooks/shared-language-lib.sh`, Stop-алерт «🗣️ Кандидаты…» в `session-collector.sh`; хранилище — `memory/shared-vocabulary.md` проекта (грузится каждую сессию, single-source — в user_profile не дублируется).

**Зависимости.** Транскрипт сессии (jq), путь словаря из cwd (кодировка каталога памяти: `/` и пробел → `-`).

**Правила.** Сигнал синтаксический: латинские/составные токены ≥ 4 символов, ≥ 3 раз за сессию, отсутствующие в словаре; частотный анализ языка не применяется (урок v1.13.3 о придуманных словарях). Служебные «user»-сообщения отбрасываются до токенизации по ПОЛЯМ, которые ставит сам харнесс (D356, корень R3): `isMeta` (тела скиллов, справка инструментов, напоминания), `origin.kind` (уведомления фоновых задач), `isCompactSummary` (сводка после сжатия контекста), `isSidechain` (ветка субагента); речь — `origin.kind == "human"` либо запись без полей. Конверты харнесса внутри речи (`<ide_selection>`, `<ide_opened_file>`, `<command-message>`, `<system-reminder>` …) вырезаются спаном, а не всей записью: за выделением в редакторе идёт реплика собеседника. Замер 12 сентября 2026 по 60 расшифровкам проекта: тела скиллов несут `isMeta` 52 из 52, уведомления задач — `origin.kind` 146 из 146, сводки — `isCompactSummary` 19 из 19. Текстового списка маркеров больше нет: он ловил половину вставок и судил по зачину. Что одного текстового признака мало, измерено ещё 8 сентября 2026: справка инструмента начинается с обычного заголовка, под маркеры не подпадала, и в кандидаты шла её лексика — «workflow», «const», «when», «phase»; на расшифровке с наибольшим числом вставок кандидатов было 5 и все пять из вставок, после `isMeta` — 0. Названные пределы: цитата системного сообщения внутри речи собеседника полей не имеет и читается как речь; новый конверт харнесса до внесения в список тоже — показание пункта D356 считает такие строки по зачину `^<[a-z_-]+>`. Детектор молчит в проектах без заведённого словаря. Кириллические термины — за пределами уровня (ждёт pad_words-подхода). Тест: test_shared_language_lib.
