# Модуль: совместный язык (мост L3↔L7)

**Назначение.** Предлагать кандидатов в shared vocabulary из речи собеседника; словарь курирует человек.

**Файлы.** `hooks/shared-language-lib.sh`, Stop-алерт «🗣️ Кандидаты…» в `session-collector.sh`; хранилище — `memory/shared-vocabulary.md` проекта (грузится каждую сессию, single-source — в user_profile не дублируется).

**Зависимости.** Транскрипт сессии (jq), путь словаря из cwd (кодировка каталога памяти: `/` и пробел → `-`).

**Правила.** Сигнал синтаксический: латинские/составные токены ≥ 4 символов, ≥ 3 раз за сессию, отсутствующие в словаре; частотный анализ языка не применяется (урок v1.13.3 о придуманных словарях). Служебные «user»-сообщения отбрасываются до токенизации. Детектор молчит в проектах без заведённого словаря. Кириллические термины — за пределами уровня (ждёт pad_words-подхода). Тест: test_shared_language_lib.
