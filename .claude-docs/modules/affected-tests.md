# affected-tests — набор тестов перед коммитом видит сканеры дерева и старый текст интерфейса

**Назначение.** В проекте без карты зависимостей «затронутые тесты» обычно отбираются по импортам изменённого модуля или по одному каталогу (`tests/unit`). Так не попадают тесты, которые сами читают дерево файлов (реестры-сканеры), и тесты, ищущие на экране подпись, которую правка убрала (e2e). Скрипт печатает набор, где есть и те и другие; хук на `git commit` называет команду, если набор для нынешних изменений не собирался.

**Файлы.** `scripts/affected-tests.sh` — набор и след; `hooks/affected-tests-reminder.sh` (PreToolUse на `Bash`, регистрация — `install.sh`, группа с `changelog-reminder.sh`); свидетель `hooks/tests/test_affected_tests_reminder.sh` (11 ног: напоминание, тишина после сборки, правка после сборки, одни `.md` — и с кириллицей в имени, не-коммит, ClaudSoul, нет скрипта, прибор не ответил, правка только в индексе, самопроверка скрипта). Самопроверка скрипта — `bash scripts/affected-tests.sh --self-test` (23 ноги: по одной на каждое правило набора, его границы и каждое условие следа; 21 мутант, снимающий по одному условию, ею убит).

**Правила набора.**
- По имени — тест, где стоит имя изменённого файла без расширения; у `index` — имя каталога, у общих имён (`page`, `route`, `utils` …) и коротких (меньше 4 букв, вроде `ru`) — «каталог/имя» либо оба куска в кавычках (путь из `path.join`). Переименованный файл называется и старым путём. Изменённый тест входит сам.
- Сканер дерева — тест, в чьём тексте есть чтение каталогов (`readdirSync`, `glob`, `os.walk`, `rglob`, `git ls-files`, `grep -r`, `git grep`, `find … -name` …), либо подключающий относительным импортом помощника с таким чтением. Входят ВСЕ сканеры: их зависимость от правки по импортам не видна.
- Старый текст — тест, где строкой целиком (в кавычках, разметке, `/…/`) стоит литерал или текст разметки, бывший в удалённых строках `git diff HEAD` и не вернувшийся в добавленных. Граница — и якорь регэкспа (`/^Далее/`), и подстановка шаблона (`` `Далее ${n}` ``). Подстрокой не судится: подпись `Invoice` иначе совпадала с именем модели в 296 тестах ProjectA.

**След.** Собранный набор пишет отпечаток изменений (вершина и содержимое изменённых путей — против HEAD, в индексе и неотслеживаемых; от `git add` не зависит) в `$STATE_DIR/affected-tests-<ключ дерева>.json`; `--was-run` отвечает 0, если отпечаток тот же (или тестов в проекте нет), 1 — если нет. Хук спрашивает только его: своей копии сверки у хука нет.

**Молчит хук.** Событие не `git commit`; дерево — сам ClaudSoul (там выбор у `hooks/tests/run_all.sh --changed`); скрипта нет; изменены одни `.md`; набор для этих изменений собран.

**Замер (15 ноября 2026).** Правка словаря B645 в ProjectA (8a0dce21), воспроизведённая в клоне: набор 291 тест из 2680 — по имени 162, сканеры дерева 116, старый текст 23; в нём все три проявления повода — `web/tests/e2e/task-create-modal.spec.ts`, сканер кабинета adv-cabsess (через помощника `tests/support/cabinet-refusal-places`), реестры b283 и b365 (через `tests/support/prisma-data-scan`).

**Названные пределы.** Хук судит «набор собран», а не «набор прогнан» — запуск тестов проекта не виден; условие снятия — журнал прогона тестов проекта. Признак сканера — словарь и один уровень относительных импортов JS/TS: помощник помощника, `source` в тестах оболочки и импорт пакетом в питоне не узнаются. Общее имя тянет лишнее: правка одного из 31 роута `[id]/route.ts` ProjectA — 183 теста по имени. `git commit` внутри `bash -c '…'` хук не видит — предел владельца разбора команды.
