# Модуль: подмена личных файлов при публикации (publish-replace)

**Назначение.** Публиковать файлы, нужные публичной версии структурно, но личные по содержанию целиком: построчный redact бессилен, когда географию выдают заголовки секций.

**Файлы.** `scripts/publish/replace/` (зеркало путей; жилец — `knowledge/source-tiers.md` → публичный шаблон), шаг 2b в `scripts/publish-public.sh`, растяжки в `scripts/publish/forbidden.txt`.

**Зависимости.** Конвейер публикации (archive → exclude → replace → redact → согласование производных чисел → гейт, включая pytest по копии снимка); гейт по собранному дереву доказывает, что подмена состоялась.

**Правила.** Выбор механизма по месту личного сигнала: токен → redact, файл не нужен наружу → exclude, личное в структуре → replace + растяжки. Протухший путь подмены роняет сборку, а не создаёт сироту. Тесты: T9/T9b/T9c в test_publish_public (replace/ и forbidden.txt сторожат друг друга).
