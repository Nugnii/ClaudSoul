# Модуль: снимок перед мутацией (mutation-snapshot)

**Назначение.** Снимок правимого файла, имя которого выдаёт инструмент, а не агент: параллельные агенты одной песочницы не могут перезаписать снимок друг друга, а восстановление отказывается от изменённого снимка и идёт в записанный при снятии путь.

**Файлы.** `scripts/mutation-snapshot.sh`; `hash_file` в `hooks/hash-lib.sh`.

**Зависимости.** `hooks/hash-lib.sh` (выбор md5sum/md5/cksum — один владелец); `mktemp`; каталог `$SNAPSHOT_DIR` либо `${TMPDIR:-/tmp}/claudsoul-snapshots/<CLAUDE_CODE_SESSION_ID>`.

**Правила.** Имя не выбирается вызывающим (D344, 7 сентября 2026). Восстановление берёт путь из записи `<снимок>.meta`, не из аргумента. Хеш сверяется до копирования; изменён — отказ кодом 2, файл не тронут. Снимок без `.meta` — не снимок этого инструмента, отказ. `take` несуществующего файла — код 2 и пустой stdout. Уровень: инструмент плюс правило в docs/development.md; страж отказа не ставится, пока точность признака не измерена (предел с условием снятия — там же). Тест: test_mutation_snapshot.
