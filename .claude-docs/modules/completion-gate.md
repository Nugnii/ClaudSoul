# completion-gate — закрытие судит команда пункта, а не отчёт

**Назначение.** Инженерная эскалация `pattern-completion-by-internal-proxy` (confirmed 14 ≥
порога 12, заявка 2026-08-16, исполнена 2026-08-31): задача объявлялась завершённой по
внутреннему прокси — объёму сделанного, факту артефакта, отчёту исполнителя — а не сверкой
с внешним критерием. У пункта долга внешний критерий машинный: строка
`**Проверка.** \`команда\` → 0` из контракта BACKLOG.md. Гейт прогоняет команду и верит
коду возврата.

**Два рубежа.**
- `hooks/completion-gate.sh` — Stop, инжект-уровень: ☑-пункты обоих бэклогов (ClaudSoul
  абсолютным путём + локальный по cwd, как у backlog-touch-check) с D-номером ≥
  `CG_MIN_ID` (200) и строкой «Проверки» прогоняются (`CG_MAX`=3 за файл,
  `CG_TIMEOUT`=60 c); красный код возврата → systemMessage с исполнимой альтернативой
  (почини мир либо верни ◐). Кэш по mtime: файл, чьи ☑ прошли зелёными и не менялся,
  повторно не гоняется; красный файл кэша не получает — напоминает каждый Stop.
  Кэш пишется только на явном статусе «ok» из разборщика (прожарка 31.08): сбой питона
  и частичное покрытие (☑-пунктов с командой больше `CG_MAX`) кэша не получают — пустой
  вывод сам по себе зелёным не считается; метка пункта — первый глиф строки, как у
  архиватора; не-UTF-8 байт разбор не роняет (errors=replace).
- `scripts/backlog-archive.sh` — неотвратимость: ☑ с красной «Проверкой» в архив не
  переносится (то же место, где отсекались ☑ без строки и ⊘ без «Вердикта»);
  `BACKLOG_ARCHIVE_RUN_CHECKS=0` — аварийное отключение, `BACKLOG_CHECK_TIMEOUT` — предел.

**Названный предел.** Покрыт только пункт долга: у «скилл выполнен» и «задача сделана»
машинного события завершения и машинного критерия нет — их слой держат skill-review-check
(контракт DoD в файле скилла) и дисциплина. Пункты без D-номера и младше порога контракта
не судятся — задним числом контракт не вменяется (прецедент ложных отказов 40/32).
Условие снятия: у «скилл выполнен» / «задача сделана» появится машинный носитель
завершения с исполнимой проверкой (аналог строки «Проверка» у пункта долга) — тогда
гейт расширяется на этот слой.

**Тесты.** `hooks/tests/test_completion_gate.sh` (красное названо / зелёное молчит /
контракт не задним числом / кэш держит и сбрасывается по mtime / локальный бэклог /
тихая деградация); красная ветка архиватора — smoke в той же сессии, ложных отказов на
фикстурах архиватора нет (`hooks/tests/test_backlog_archive.sh`).
