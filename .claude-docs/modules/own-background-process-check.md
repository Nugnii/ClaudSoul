# own-background-process-check — свой фоновый сервер на границе хода называется в том же ходе

**Назначение.** Хук на `Stop` (синхронный): фоновая задача этой сессии, у которой процесс держит порт TCP на прослушивании, называется агенту — номер задачи, порт, PID, возраст, команда, — и ход продолжается, чтобы сервер был погашен, пока владелец ещё здесь. Раз на задачу в сессии (дроссель `state/own-bg-server-fired-<sid>.jsonl`): ключ — номер задачи, а не «задача:порт», потому что набор тестов, слушающих порт 0, на каждой границе показывал бы новый порт и продолжал ход заново (скептик D1313, H1). Отметка сверяется после записи: не легла — хук молчит, а не зовёт ход без конца.

**Признак «своя задача» — из ядра.** Корень — ближайший предок хука с именем `claude`. Прямой потомок корня, у которого fd 1 — файл `…/tasks/<id>.output`, — команда харнесса этой сессии; всё её поддерево — её процессы; слушающие порты берёт `lsof -iTCP -sTCP:LISTEN`. Серверы MCP — тоже потомки корня, но их вывод — труба; процессы других сессий висят под другим корнем.

**Молчит:** задача без порта; слушающий процесс вне дерева сессии; задача уже названа; нет `lsof` или корня (в `--dry-run` — код 2 «НЕ ИЗМЕРЕНО»).

**Почему порт, а не «задача жива».** Реплей 30 расшифровок 17 ноября 2026: границ хода 443, с живой фоновой задачей 318 — законный порядок «прогон фоном, жду уведомления»; признак «жива» перезапускал бы каждый второй ход. Серверных задач, живых на границе, 43.

**Файлы.** `hooks/own-background-process-check.sh` (регистрация — `install.sh`, Stop), свидетель `hooks/tests/test_own_background_process_reported.sh` (24 ноги на настоящих процессах; 15 мутантов — без фильтра файла задачи, без каталога `tasks`, без окончания `.output`, без признака порта, без состояния LISTEN, без дросселя, ключ с портом, без сверки отметки, без корня, без подъёма к предкам, без первого слова `claude`, без второго, сухой прогон с кодом 0, дроссель без сессии, без спуска к внукам — каждый роняет свою ногу).

**Зависимости.** `ps`, `lsof`, `jq`; `hooks/paths-lib.sh` (`resolve_session_id`), `hooks/throttle-lib.sh`.

**Чем решалось раньше.** Правило «свой сервер гашу сам» в памяти проекта ProjectA — текстом, не удержало трижды (D1313). `hooks/mcp-orphan-reap.sh` остаётся: он снимает серверы MCP с мёртвым родителем на SessionEnd, признак и момент другие.

**Названные пределы.** Цикл ожидания без порта не ловится. Отвязанный процесс (`cmd &` внутри команды, `nohup … &`, `setsid`) уходит под launchd и выпадает из дерева (метки сессии в ядре macOS у него нет); `nohup` — в 5 фоновых командах из 2637. `exec сервер > журнал` в задаче не узнаётся (0 из 2637). Смена формы `tasks/<id>.output` в харнессе сделает хук немым, а `--dry-run` скажет «0», а не «не измерено» (наблюдений 0). Команда переднего плана фонового субагента, держащая порт на границе хода родителя, тоже будет названа — раз.

**Повод.** D1313, `pattern-own-background-process-outlives-its-purpose`.
