# behavior-condition-probe — у свидетеля-атаки условие явления создаётся, а не предполагается

**Назначение.** Выхолостить предмет свидетеля-атаки и посмотреть, покраснеет ли он. Честная нога обязана покраснеть; зелёная на мёртвом предмете — ложно-зелёная. Прибор считает три числа: сколько свидетелей, у скольких предмет разрешим механически, сколько среди них ложно-зелёных.

**Файлы.** `scripts/behavior-condition-probe.sh`, свидетель `hooks/tests/test_behavior_condition_probe.sh` (11 проверок, 4 мутанта). Потребитель — строка «Проверка» пункта D342 в `BACKLOG.md`.

**Зависимости.** `git archive HEAD` (работа идёт по снимку, рабочее дерево не правится), `python3` для разрешения предмета, `mktemp`.

**Правила.**
- **Условие создаётся ПО РОЛИ предмета.** Исполняемый механизм выхолащивается заглушкой с немедленным выходом; источаемая библиотека — ПУСТЫМ файлом. Заглушка внутри `source` убивает вызывающего, и тест выходит нулём, не дойдя до итоговой строки: получается ложно-зелёный, порождённый самим зондом. Измерено 14 сентября 2026: без различения роли 3 ложно-зелёных из 8, все три артефакты; с различением — 0 из 8.
- **Неразрешимый предмет считается ОТДЕЛЬНО от ложно-зелёного** — это разные исходы с разными решениями, и слить их в одно число значило бы пустить два смысла по одному проводу.
- **Пустой универсум — отказ прибора (код 2), а не чистота.** Ноль свидетелей не означает «всё честно».
- Рабочее дерево не изменяется: все правки идут в снимке `git archive`.

**Названный предел.** Предмет разрешим у 8 свидетелей из 204 — тех, кто зовёт механизм через переменную корня либо объявляет его переменной с суффиксом SRC. Остальные 196 предмет не называют, и зонд для них неисполним. Это нынешняя открытая часть D342, а не дефект прибора; условие снятия — свидетель объявляет свой предмет. **Условие снятия** (дописано 14 сентября 2026): свидетель-атака объявит свой предмет так же, как это делают восемь разрешимых — вызовом через переменную корня либо переменной с суффиксом SRC; тогда зонд станет исполним на всём универсуме, и предел исчезнет сам, без правки прибора.

**Повод (D342).** Восемь заходов искали ТЕКСТОВЫЙ признак «условие не создаётся», и все восемь отвергнуты числом. Прежняя «Проверка» пункта судила ИМЯ ФАЙЛА (`ls` по шаблону имени) — пустая заглушка с подходящим именем её зеленила, что пункт и признавал меткой о суждении по форме. Девятый заход поведенческий, и он дал первое число.
