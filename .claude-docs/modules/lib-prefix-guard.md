# lib-prefix-guard — пространство имён библиотеки объявлено и сверяется

**Назначение.** Не дать появиться в `hooks/*-lib.sh` функции с префиксом, которого нет в
объявлении этой библиотеки. Предмет — принадлежность имени пространству, а не его
существование: существование держит `undefined-function-check`.

## Файлы

| файл | роль |
|---|---|
| `hooks/lib-prefix-guard.sh` | страж, `PreToolUse[Write\|Edit\|MultiEdit]` |
| `hooks/*-lib.sh`, строка `# ПРЕФИКСЫ:` | объявление пространства имён (34 из 34) |
| `hooks/tests/test_lib_prefix_guard.sh` | 7 ног, включая контроль по всему дереву |

## Устройство

Объявление в шапке библиотеки перечисляет префиксы через пробел. Страж берёт объявление у
файла на диске (для нового файла — из записываемого текста), находит определяемые функции
в записываемой части и называет те, что не начинаются ни с одного объявленного префикса.

**Под правило не подпадают:** имена с ведущим `_` (внутренние), файлы без объявления
(сверять не с чем), не-библиотеки.

## Почему сперва объявление

Замер 11 сентября 2026: правила именования не было ни в одном документе, в библиотеках
45 разных префиксов, и лишь **10 из 21** библиотеки с 3+ функциями держали 80%+ имён под
одним. Признак «префикс совпадает с самым частым в файле» дал бы **11 ложных из 21**.
Потому порядок обратный: сперва объявление, собранное ИЗ ФАКТА, затем сверка — то же
устройство, что у карты корней (`ROOTS.md` + `scripts/root-map.py`).

## Уровень и его основание

**Подсказка, не отказ.** Точность на живых правках не измерена, а отказ уровня 4 заводится
только с измеренной точностью на признаке с одним последствием. Положительный контроль при
заведении: страж прогнан по всем 34 библиотекам и промолчал на каждой.

## Названный предел

Имя, ВЫДУМАННОЕ с верным префиксом (`rc_trace_counts` при живом `rc_trace_text`), этот
страж пропускает по построению — префикс-то свой. Такое ловит `undefined-function-check`
по факту существования. Предел закреплён ногой T5 теста: если страж заговорит на верном
префиксе, тест покраснеет.

**Условие снятия:** предел держится, пока пространство имён объявлено ТОЛЬКО
префиксом. Появится объявление ПОЛНОГО состава — список имён, которые библиотека
экспортирует, рядом с `# ПРЕФИКСЫ:` — и страж сможет судить не о начале имени, а о его
принадлежности объявленному составу; тогда `rc_trace_counts` при отсутствии в списке
будет назван здесь, а не только при исполнении. Цена решения не оценена: состав придётся
держать в согласии с кодом, то есть у него самого появится тот же вопрос сверки.

## Повод

Слово владельца 11 сентября 2026: «должен быть какой-то механизм по неймингу функций при
создании новой» — после того, как имя `rc_trace_counts` было выведено из ряда соседних.
Тот же класс стоил проекту D318 (`_cm_merge_into` по образцу `_cm_write_managed_block`).
