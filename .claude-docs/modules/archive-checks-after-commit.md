# archive-checks-after-commit — коммит, ломающий «Проверку» закрытого пункта, назван на следующей реплике

**Назначение.** «Проверки» закрытых пунктов архива прогонял только недельный замер, а набор гоняет `hooks/tests/test_*.sh`:
коммит, ломающий пробу закрытого пункта, проходил зелёным, и поломка всплывала через неделю знаком «?». Прибор после
коммита прогоняет «Проверки», которые задевают файлы коммита, и кладёт строку в очередь напоминаний, если хоть одна не
держится. Решение владельца 8 ноября 2026 (D1249): фоном ПОСЛЕ коммита — коммит не ждёт.

**Файлы.** `scripts/archive-checks-after-commit.sh`; зовёт его ловушка git `post-commit` (`hooks/commit-trap.sh
--post-commit`) отсоединённым процессом, только из основного репозитория ClaudSoul; проба
`hooks/tests/fixtures/probe_D1249.sh` (ноги: безвредная правка, незакоммиченная поломка, пункт ⊘, коммит через
поставленную ловушку с унаследованным GIT_DIR и брошенным замком). Выход один — строка в канале проекта ClaudSoul `state/project-signals-<ключ>.txt` (`project_alert`, D1304); журнала нет (читателя у него
не было — род G).

**Зависимости.** Исполнитель сверки архива по номерам — `hooks/tests/fixtures/probe_D1196.sh` (ручка
`PROBE_ARCHIVE_IDS`), он зовёт `scripts/backlog-recheck.sh --archive`; очередь напоминаний показывает
`hooks/pending-alerts-surface.sh`.

**Правила.**
- Выбор номеров: закрытый пункт ☑ с исполнимой «Проверкой», у которого проба объявляет в `# СУДИТ:` файл коммита (по
  имени), проба ПОДКЛЮЧАЕТ или ИСПОЛНЯЕТ файл коммита кодом — строка с командой `.`, `source`, `bash`, `sh`,
  `python`, `cp` называет его имя целиком, с границей (`my-x.sh`, `x.sh.bak` — не `x.sh`; D1312: правка
  `alerts-read.sh` не перепроверяла D441, D514, D1231, которые его подключают), либо «Проверка» называет путь файла
  коммита. Прочее упоминание в коде — данные (путь в присваивании, текст сообщения, подделка в песочнице) и выбора не
  даёт: первая редакция брала любое упоминание, 40% добавок были данными, а проба D1249 выбирала сама себя за файл,
  который правит в клоне. Цена — замер по 200 коммитам: 69 запусков сверх объявленных (против 344 у первой редакции). Какие пункты есть и где кончается каждый, отбор спрашивает у
  исполнителя (`scripts/backlog-recheck.sh --archive --list` — номер и команда, без исполнения; D1283): своё выражение
  не считало границей заголовки `### D… ☑` старого вида, «блок» D104 вбирал «Проверки» десятков старых пунктов (D112,
  D211, D227 терялись), а D447 выбирался по пробе без исполнимой «Проверки». `--select <файл>…` — только выбор по
  рабочей копии. Учёт `.claude-docs/dep-index.tsv` выбора не даёт. Документ `.md` не даёт выбора по тексту
  «Проверки» и по коду пробы (то же правило, что у выборки набора, `hooks/tests/run_all.sh`, D1203: имя BACKLOG.md
  в «Проверках» гнало бы архив на каждый коммит), но даёт его по строке «СУДИТ»: предмет объявила сама проба (D1338).
- Номер, чья «Проверка» зовёт пробу «только в рабочем дереве», не выбирается. Перечень таких проб даёт прибор свидетелей
  (`scripts/behavior-condition-probe.sh --realtree`; прибор без этого режима не спрашивается — он начал бы полный
  прогон). Такая проба судит то, чего в клоне нет: неотслеживаемый снимок карты (D411, D1009) или журнал прибора по пути
  дерева (D474). Скептик opus по D1295 (M2): в рамке клона код 2 «не измерено: D411 D1196» уходил напоминанием «не
  держатся». Их судит недельный прогон архива в настоящем дереве.
- Пункт ⊘ (не делается) инварианта не объявляет и не выбирается: исполнитель судит только ☑, и выбранный ⊘ давал
  код 2 «в архиве нет закрытых пунктов» без прогона (скептик opus по 2fda3705, H1).
- Судится снимок коммита — клон с общими объектами на вершине, запомненной в начале прогона, а не рабочая копия:
  незакоммиченная правка или правка во время прогона коммиту не винится (M2).
- Один прогон за раз — замок `hooks/state-lock-lib.sh` с владельцем: брошенный убитым прогоном срывается по живости
  владельца, живой держит до часа (M1). Фоновый прогон — отдельный процесс, а не подоболочка: владелец замка — `$$`.
- Код 0 всегда (ловушку коммита прибор не роняет); `--sync` — прогон на месте с кодом исполнителя (0 держатся,
  1 красны, 2 не измерено), 3 — нечего судить.
- Нечего судить и держатся — тишина.

**Молчит.** Нет архива или исполнителя (другой проект); коммит без файлов или только из документов, которых не объявила ни одна проба; коммит в клоне или
рабочей копии `git worktree`.

**Названные пределы.** Прогон, начатый при уже идущем, пропускается молча; проба, подключающая файл через переменную
(`L="$R/x.sh"; . "$L"`) или собирающая имя сборкой строки, не выбирается — зависимость читается по строке-подключению. Условие снятия — учёт зависимостей
начнёт знать пробы. Строку показывает ближайшая
сессия проекта ClaudSoul (канал проекта, `hooks/pending-alerts-surface.sh`; прежде — первая сессия системы, M6). Снятие `GIT_*` стоит дважды, у запуска в ловушке и в начале прибора, и свидетель
различает только снятие обоих разом. Список файлов и снимок берутся от одной запомненной вершины; мутант «список от
`HEAD`» проба не различает — окно гонки внутри прогона меньше секунды.

**Повод (D1249).** Финальный скептик opus по ad26ce48 (5 ноября 2026, D1209, H1): пять «Проверок» архива стали 0 → 2
коммитом, прошедшим полный набор 665 из 665.
