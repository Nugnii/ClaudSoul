# Модуль: объявленный результат инструмента измерен (instrument-result-measured)

**Назначение.** Для каждого инструмента `scripts/` установить ПОВЕДЕНИЕМ, а не чтением, что его объявленный результат кто-то меряет: есть тест, который краснеет, когда инструмент подменён заглушкой `exit 0`, и зелен на живом инструменте. Упоминание имени инструмента в тесте, тест «только код 0», сломанный тест и зависание измерением не считаются.

**Файлы.** `scripts/instrument-result-measured.sh`; тест `hooks/tests/test_instrument_result_measured.sh`; снимок `$STATE_DIR/instrument-result-measured.tsv` (инструмент, ключ, вердикт, свидетель, секунды, дата, причина); замер `instrument-result-measured` в `scripts/measurements.tsv` (период в коммитах).

**Зависимости.** `hooks/hash-lib.sh` (ключ снимка — хеш инструмента и всех кандидатов), `hooks/lib/universe-lib.sh` (универсум из индекса git), `hooks/state-lock-lib.sh` (запись снимка под замком), `suite-baseline.tsv` (порядок кандидатов дешевле-первыми; без базиса — порядок по имени), `git`, `tar`, `perl` (сторож: своя группа процессов, по сроку снимается вся).

**Правила.** Дерево копируется из индекса git вместе с `.git` во временный каталог; мутация только в копии, рабочее дерево не трогается. Кандидаты в свидетели — только тесты из индекса git (тот же владелец, что у копии): тест из строки «Проверка результата», затем `test_<имя>.sh`, затем тесты, упоминающие имя инструмента буквально и целиком (подстрока `log.sh` в `activity-log.sh` не считается); один `grep` на инструмент. Красный под заглушкой кандидат обязан оставить след исполнения заглушки (`IRM_TRACE`; тест, судящий о байтах файла — `git diff`, хеш, размер, — не свидетель) и быть зелёным без заглушки, иначе это сломанный тест. Сторож отвечает 124 только по сроку; код ≥128 от самого теста — красный, не «завис». Снимок обесценивается правкой инструмента либо любого кандидата; `--check` читает снимок против дерева и не пишет. Коды: 0 — все измерены (для `--check`: и свежи), 1 — есть не измеренные или устаревшие, 2 — прибор сломан (универсум пуст, копия не собралась, нет библиотек). Ключ снимка — содержимое инструмента и имя+содержимое каждого кандидата, отсортированные по имени: порядок цен базиса в ключ не входит, переименование кандидата его обесценивает. Заглушка сохраняет шапку (тест формы под ней остаётся зелёным и свидетелем не становится) и кончается `return 0 || exit 0` (свидетель через `source` засчитывается). Копия разыменовывает симлинки (`tar -h`); linked worktree получает свой git без истории; без perl замер не начинается (код 2, снимок не тронут); каталог сессий свой у каждого плеча. Прожарка 12 сентября 2026: 9 атак, 5 классов, все закрыты, тесты `test_adv_irm_*` остались в дереве. Названные пределы: заглушка различает «мёртв/жив», а не «режим проверки меряет объявленный результат, а не соседний» — условие снятия: мутант «ветка проверки всегда отвечает 0» и фикстура под инструмент, на которой свидетель краснеет (образец `test_split_provenance_log.sh`); HOME и STATE_DIR общие для обоих плеч — тест, пишущий состояние туда, обманет прибор тем же способом, что атака 3; условие снятия — песочница HOME на каждое плечо.
