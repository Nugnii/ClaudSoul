# adversary-recall — полнота критика `/adversary` на поломках с известным ответом

**Назначение.** Критик `/adversary` находит дефекты, но какую ДОЛЮ настоящих — не мерил никто: соседний
`scripts/adversary-replay.sh` мерит другое — уходят ли крупные коммиты без прогона вовсе. Модуль даёт число: из поломок,
которые проект уже нашёл и починил, сколько критик находит сам, не зная ответа. Приём — из статьи команды Claude Code
«How the Claude Code team thinks about verification» (16 ноября 2026): проверять проверяющего на ошибках, которые
действительно случились; засчитывать только находку, описывающую именно эту поломку. Решение владельца 18 ноября 2026.

**Файлы.** `scripts/adversary-recall.sh` (снимки и задание критику), `scripts/adversary-recall-corpus.tsv` (корпус:
номер, род, коммит, файл, ключ ответа). Проверка прибора — `bash scripts/adversary-recall.sh --self-test`.

**Как работает.**
- Случай `bug` — коммит ПОЧИНКИ; снимок берётся на его родителе. Случай `control` — коммит состояния файла, у которого
  за историю нет ни одной починки.
- Снимок — `git archive` без истории: сообщения коммитов «D<N> в работе — разбор» подсказали бы ответ. Из снимка убраны
  журналы долга и сессий (BACKLOG, SESSION, CHANGELOG) и каждый файл, кроме предмета, где номер пункта стоит словом
  (проба `probe_D<N>.sh`, журнал активности). Самопроверка сверяет: предмет равен коду до починки, номера не осталось.
- Задание критику (`prompt <id> <снимок>`) собирается из тех же `CRITIC` и `TECHNIQUES`, что у
  `skills/adversary/references/adversary-rounds.js`, с границей «работай только в снимке». Критик — та же модель, что у
  `/adversary` (opus), один раунд, агент `lean`.
- Засчитывается только находка, описывающая поломку ключа; соседние настоящие дефекты в счёт полноты не идут.

**Сравнение на одних случаях — корпус 2 без правила 10** (решение владельца «сравнить на одних случаях»; задание
отличается от плеча с правилом ровно четырьмя строками правила). Найдено **1 из 8** — тот же D1259; остальные шесть
пропущены и здесь, D1207 — без частичного попадания. Атаки на вселенную (неотслеживаемый файл, подкаталог сессии,
`Icon\r`) критики без правила нашли тоже, то есть и сдвиг атак правилу не принадлежит. D1286 критик без правила
рассматривал (счёт тройных кавычек, SQL-литералы `mcp-server/storage.py`), но атакой не сдал. Решение владельца
18 ноября 2026 — правило 10 снято: `/adversary` возвращён к тексту 1.6.0, в установку правило не попадало.
Корпус 2 оказался труднее корпуса 1 при любом задании (1 из 8 против 4 из 8); рычаг полноты — не текст правила.

**Сверка корпусов.** `--self-test` проверяет, что у каждого случая коммит — ПЕРВАЯ починка пункта (номер первым
словом после `fix(…):`) и что предмет до неё номер не называет. Сверка нашла в корпусе 2 круг правок скептика вместо
починки (D1261) и предмет, сам называвший поломку пределом, — случай заменён на D1307.

**Названные пределы.**
1. Контроль не мерит ложные тревоги без разбора каждой атаки: «файл без починок» не значит «файл без дефектов» — на
   обоих контрольных критик воспроизвёл настоящие дефекты (C1 — D1324, C2 — обходы `replace-uniqueness-guard`, D1323).
2. Правило критика, выведенное из пропусков этого корпуса, мерить на нём же нельзя: подгонка под экзамен. Для него нужен
   новый набор случаев.
3. База знаний `~/.claude/global-lessons` вне снимка, но кейс о поломке там может лежать; критик идёт агентом `lean`
   без CLAUDE.md, и граница задания запрещает её чтение.
4. Восемь случаев — малая выборка: одно найденное или пропущенное меняет долю на 12 пунктов.
5. Цена замера — 10 агентов opus, от 11 до 72 минут каждый.

**Разбор попутных атак (D1325).** Замер попутно дал 228 воспроизведённых атак на 16 файлов. Исход каждой —
строкой `hooks/tests/fixtures/adversary-recall/2026-11-18-triage.tsv`: 199 отнесены к пунктам долга по предмету
(D1326–D1341), 1 — к D1324, 17 — «предел» (частота формы 0 на 99 023 командах либо ограничение уже названо в
предмете), 11 — «не дефект». Пробы пунктов зовут `hooks/tests/fixtures/probe_attacks.sh <номер>`: тесты атак пункта
берутся из архива вне репозитория и исполняются на копии рабочего дерева; без архива ответ — 2, «не измерено».
