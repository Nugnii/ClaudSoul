# costly-tests — цена теста считается процессорным временем, оправдание — строкой реестра

**Назначение.** Дорогой тест — тот, что зовёт прибор целиком вместо своего предмета, и цену
такого теста нельзя читать по стенным секундам: под восемью потоками тест делит ядра с
соседями и дорожает в разы (тест кэша реестра — 38 с в одиночку, 282 с в полном прогоне).
Процессорное время под нагрузкой тоже завышено — ядра машины разнородные (тот же тест: 123 с
CPU в прогоне при 38 с в одиночку), — поэтому журнал прогона служит лишь ФИЛЬТРОМ кандидатов
(его колонка CPU — надмножество дорогих), а цена меряется ПООДИНОЧКЕ режимом `--measure`
(`state/suite-cost.tsv`). Прибор требует у каждого теста с ценой поодиночке ≥ 20 с CPU либо
удешевления, либо строки реестра с измеренным числом и причиной, почему цена неустранима.
Устаревшее оправдание (тест подешевел, исчез) — находка.

**Файлы.** `scripts/costly-tests.sh` (прибор: `--measure` меряет кандидатов поодиночке и судит, без
аргумента только судит последний замер; порог `COSTLY_CPU_MAX`, умолчание 20);
`hooks/tests/costly-justified.tsv` (реестр: имя ⇥ цена с датой ⇥ причина);
`hooks/tests/run_all.sh` — пишет CPU четвёртой колонкой `state/suite-run.tsv` и по завершении
полного прогона сохраняет копию журнала в `state/suite-run-full.tsv` (выборочные прогоны стирают
оригинал за минуты) (разность `times`
в самой оболочке до запуска и после ожидания; в подстановке `$(…)` счётчик детей нулевой) и
печатает CPU рядом со стенными в разделе «ДОРОЖЕ»; реестр замеров — строка `costly-tests`
(50 коммитов). Свидетель `hooks/tests/test_costly_tests.sh` — 11 ног, включая настоящий
замер поодиночке фикстурного теста и мутант без сравнения с порогом.

**Коды.** 0 — дорогих без оправдания нет и реестр свеж; 1 — находки названы поимённо (дорогой
без строки, строка без числа или причины, строка о подешевевшем или исчезнувшем тесте); 2 —
не измерено: замера поодиночке нет (для `--measure` — нет журнала полного прогона).

**Названные пределы.** Замер стареет с каждым полным прогоном: новый дорогой тест виден в
журнале, но не в замере, пока `--measure` не повторён; проверка называет таких кандидатов
предупреждением, а не находкой, срок держит реестр замеров (50 коммитов). CPU считается по
детям, которых оболочка дождалась: убитый сторожем процесс в цену входит не весь (виден кодом).
Спящий тест дёшев по CPU и дорог стенными секундами — предмет D340. Числа — с машины, где мерили, и шумят до ±50% между замерами (67 и 46 с у одного
теста) — потому строка реестра устаревает лишь при цене ниже половины порога (гистерезис).
