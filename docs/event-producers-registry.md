# Реестр продюсеров событий

> Документ состояния: кто пишет события в журналы и чем каждый отличает **акт** от
> **наличия признака**. Первый шаг D88 — перечень, не правка. Хроника — CHANGELOG.
> Снят 2026-08-27.

## Зачем

`provenance_log` знания ведётся тщательно, но происхождение самого **наблюдения** не
проверяется: запись «поправка собеседника, сессия X» неотличима в журнале от
«процитированный собеседником чужой текст, сессия X». Различие лежит до confidence, до
взвешивания опровержений и до промоушена — то есть ошибка класса распространяется дальше,
чем ошибка значения.

D88 требует именно перечня и запрещает вводить поверх него шкалы и параметры (включая
`propagation_risk` из внешней рецензии) до того, как перечень существует. Здесь перечень;
параметров нет намеренно.

## Как собран

Не по памяти и не по списку из формулировки пункта. Отправная точка — сами журналы:
`ls ~/.claude/hooks/state/*.jsonl`, свёрнуто по видам (идентификатор сессии → `<SID>`) →
**22 вида журналов**. Для каждого вида продюсер найден `grep` по `hooks/`. Основание
детекции прочитано в коде продюсера.

## Что показал сам перечень

**1. Отсев чужой речи подключён у 6 файлов из 40, и не у всех, кому он нужен.**
Общая функция живёт в `hook-input-lib.sh` (режет markdown-цитаты, типографские кавычки,
вставленные документы). Подключают её: `activity-flush-lib`, `command-scope-lib`,
`itr-event-detector`, `intrusiveness-state-lib`, `reformulation-tracker`, `rework-detector`.
`user-correction-guard.sh` её **не подключает** — при этом он читает речь собеседника
лексическим словарём, то есть ровно тот случай, для которого фильтр писался. Замер D88
дал ему 96 срабатываний вне цитат по корпусу.

**2. Наблюдаемое делится надвое, и заражение бьёт по половинам по-разному.**
Четыре продюсера смотрят на **свой** вывод (`output-language-check`, `relative-date-check`,
`timestamp-canary-check`, `response-tracker`) — там чужой речи нет по построению, зато есть
собственный метадискурс: разбор правила про смешение алфавитов сам содержит смешение.
Остальные смотрят на речь собеседника или на состояние мира — там работает и цитирование,
и пересылка.

**3. Явный акт — ровно один из восемнадцати.** `knowledge-counter-bump.sh` пишет событие
только когда его позвали с исходом; всё прочее выводит акт из признака. Это не дефект
(структурные признаки надёжны), но объясняет, почему `disagreement-outcomes` —
единственный журнал, где «случилось» и «замечено» совпадают по построению.

**4. Мёртвый журнал.** `metrics-history.jsonl` — 16 строк, последняя запись 21 апреля
2026, продюсера в кодовой базе нет: `grep -rn "metrics-history" hooks/ scripts/` пуст.
Файл остаётся читаемым и по форме неотличим от живого.

## Чего здесь нет намеренно

- **`propagation_risk`** и любые шкалы — по прямому возражению в D88: параметр поверх
  несуществующего перечня даёт видимость точности. Перечень теперь есть; параметр —
  следующий шаг, отдельным решением.
- **Правок.** Ни один из четырёх выводов выше не починен этим документом. Каждый —
  кандидат в отдельный пункт долга со своей ценой.
