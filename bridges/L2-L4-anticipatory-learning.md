# Мост L2↔L4: Антиципаторное обучение

> Навык: учить то, что ПОНАДОБИТСЯ, а не только то, что случилось.

## Зачем

Без этого моста система реактивна: учится только на ошибках/успехах, которые уже произошли. С мостом — система ПРЕДВИДИТ, какие знания понадобятся, по направлению мысли собеседника, и заранее готовит или отмечает пробелы.

**Ценность:** Сокращение "первого промаха" — ситуаций, когда система не знает чего-то, что можно было предвидеть.

## Цикл

```
L2 (Knowledge)              L4 (Trajectory)              L2 (Knowledge)
┌──────────────┐            ┌──────────────┐             ┌──────────────┐
│ Паттерны     │──"когда X, │ Текущая      │──"мысль   → │ Пробел       │
│ траекторий   │  обычно Y" │ траектория   │  идёт к Z"  │ обнаружен:   │
│ из прошлых   │            │              │             │ знаний по Z  │
│ сессий       │            │              │             │ нет          │
└──────────────┘            └──────────────┘             └──────────────┘
       ↑                                                        │
       └──────────── новый trajectory pattern ──────────────────┘
```

## Dataflow

**L2→L4:** Знания о типичных последовательностях тем:
- "После обсуждения архитектуры обычно идёт реализация"
- "Когда собеседник спрашивает 'не пора ли?', следующий шаг — анализ готовности"
- Паттерны хранятся как cases/patterns с `trigger: trajectory_pattern`

**L4→L2:** Траектория обнажает пробелы:
- "Мышление движется к теме X, но в базе знаний нет ни одного файла по домену X"
- "Предсказание следующего шага: собеседник спросит о Y, но знания по Y устарели (last_confirmed: 6 мес назад)"

## Что даёт

| Без моста | С мостом |
|-----------|----------|
| Учимся когда ошиблись | Учимся ДО ошибки |
| Знания = прошлый опыт | Знания = прошлый опыт + прогноз потребностей |
| Пробелы обнаруживаются при столкновении | Пробелы обнаруживаются по траектории |

## Реализация

1. **В SESSION.md Trajectory:** при записи trajectory point — проверить, есть ли знания по предсказанной следующей теме
2. **В knowledge-activator:** если trajectory confidence ≥ 3 и predicted topic не покрыт знаниями → инжектировать "📍 Trajectory gap: тема [X] не покрыта знаниями"
3. **В /learn:** новый тип `outcome: anticipatory` — знание, записанное ДО столкновения с ситуацией
