# Мост L5↔L7: Мета-со-когниция

> Навык: рефлексия над качеством совместного мышления.

## Зачем

Это самый глубокий мост — рефлексия о рефлексии совместного мышления. Без него система со-мыслит, но не знает, НАСКОЛЬКО ХОРОШО. С мостом — появляется осознание: "наши совместные инсайты глубже, когда собеседник задаёт аналогии" или "со-мышление деградирует в длинных сессиях".

**Ценность:** Оптимизация самого ценного процесса — совместного мышления. Если со-мышление = главный источник прорывных идей, то его качество стоит мониторить и улучшать.

## Цикл

```
L7 (Co-Cognition)           L5 (Meta-Cognition)          L7 (Co-Cognition)
┌──────────────┐            ┌──────────────┐             ┌──────────────┐
│ Совместные   │──метрики─→ │ "Co-cognitive│──правило──→│ Адаптирован- │
│ инсайты,     │            │ insights     │             │ ный режим    │
│ pivots,      │            │ глубже после │             │ со-мышления  │
│ решения      │            │ аналогий"    │             │              │
└──────────────┘            └──────────────┘             └──────────────┘
       ↑                                                        │
       └──────────── лучшее со-мышление ────────────────────────┘
```

## Что даёт

| Без моста | С мостом |
|-----------|----------|
| Со-мышление = неуправляемый процесс | Со-мышление = наблюдаемый и оптимизируемый |
| Не знаем, что запускает лучшие инсайты | Карта: "аналогии → глубокие инсайты, прямые указания → поверхностные" |
| Одинаковый подход | Адаптация под условия, когда со-мышление наиболее продуктивно |

## Метрики

- `co_cognitive_insights_per_session` — количество инсайтов, порождённых совместно
- `insight_depth` — impact и intensity co-cognitive знаний vs solo
- `triggers_for_co_cognition` — что запускает продуктивное со-мышление (аналогии? противоречия? вопросы?)
- `co_cognition_fatigue` — деградирует ли качество со-мышления к концу длинных сессий?

## Реализация

1. **В /retro и /learn:** при `origin: co-cognition` — записывать что именно запустило со-мышление (trigger_for_co_cognition)
2. **В metrics-collector:** агрегация co-cognitive знаний: count, avg impact, avg intensity vs solo
3. **В /knowledge-audit:** секция "Co-Cognition health" — продуктивность, тренд, лучшие триггеры
4. **В правилах:** если метрики показывают что аналогии = лучший триггер → чаще предлагать аналогии
