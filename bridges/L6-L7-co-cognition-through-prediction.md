# Мост L6↔L7: Генеративное мышление

> Навык: предсказания как инструмент совместного мышления.

## Зачем

Предсказание без со-мышления = монолог. Со-мышление без предсказания = реактивность. С мостом — предсказания становятся генеративными: "я ожидаю X" → собеседник отвечает Y → расхождение рождает новое знание, которого не было бы ни у кого из участников.

**Ценность:** Продуктивный промах важнее точного попадания. Неожиданный ответ на предсказание = точка роста совместного мышления.

## Цикл

```

│ suggestion:  │            │ собеседника: │             │ модель:      │
│ "следующее—X"│            │ "нет, это Y!"│             │ "в контексте │
│              │            │ = co-insight │             │  Z → скорее Y│
└──────────────┘            └──────────────┘             └──────────────┘
       ↑                                                        │
       └──── точнее предсказания → продуктивнее диалог ─────────┘
```

## Что даёт

| Без моста | С мостом |
|-----------|----------|
| Промах предсказания = провал | Промах = генеративная точка |
| Gentle suggestion = проверка | Gentle suggestion = приглашение к со-мышлению |
| Предсказания улучшаются только количеством | Предсказания улучшаются КАЧЕСТВОМ расхождений |

## Реализация

Неявно работает через:
1. **Конструктивное несогласие (⚡)** — озвучивание сомнений = форма предсказания ("я думаю X, а ты делаешь Y")
2. **Gentle suggestion** — "Следующий шаг — X?" = предсказание-как-приглашение
3. **Prediction verification** — miss → анализ ПОЧЕМУ → со-мышление о причинах

### Для полной реализации нужно:
- Отслеживать `generative_misses` — промахи, породившие инсайты (не все промахи генеративны)
- В /learn: при miss + инсайт → `origin: co-cognition`, `trigger: predictive_miss`
- Метрика: `generative_miss_ratio` = доля промахов, ставших инсайтами
