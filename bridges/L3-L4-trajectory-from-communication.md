# Мост L3↔L4: Понимание направления мысли

> Навык: чтение траектории мышления через коммуникативные сигналы.

## Зачем

Траектория мысли невидима — видны только её проекции в сообщениях. Без моста L4 (траектория) строит гипотезы в вакууме. С мостом — каждое сообщение = точка на траектории, типизированная (generalization, pivoting, deepening...).

**Ценность:** Коммуникация — единственное окно в мышление собеседника. Мост превращает поток сообщений в карту мышления.

## Цикл

```
L3 (Communication)          L4 (Trajectory)              L3 (Communication)
┌──────────────┐            ┌──────────────┐             ┌──────────────┐
│ Сообщение:   │──точка───→ │ Траектория:  │──гипотеза─→│ Адаптация    │
│ тема, тон,   │            │ T1→T2→T3,    │             │ ответа под   │
│ вопрос/ответ │            │ гипотеза,    │             │ направление  │
│              │            │ тип точки    │             │ мысли        │
└──────────────┘            └──────────────┘             └──────────────┘
       ↑                                                        │
       └──────── точнее ответ → точнее следующая точка ─────────┘
```

## Что даёт

| Без моста | С мостом |
|-----------|----------|
| Каждое сообщение = отдельный запрос | Сообщения связаны траекторией |
| Реактивный ответ | Ответ учитывает направление мысли |
| Pivots незаметны | Pivots типизируются и отслеживаются |

## Реализация

Неявно работает через:
1. **SESSION.md Trajectory** — запись точек T1, T2... с типизацией (generalization, pivoting, deepening, returning, challenging)
2. **Правила в CLAUDE.md** — "After 3+ significant messages, start tracking trajectory"
3. **Prediction** — гипотеза о следующем сообщении на основе траектории

### Для полной реализации нужно:
- Формализовать mapping: тип сообщения → тип точки (сейчас ручная оценка)
- Автоматическое определение pivots через изменение topic/keywords
- Обратная связь: точность предсказаний → качество чтения траектории
