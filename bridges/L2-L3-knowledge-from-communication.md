# Мост L2↔L3: Обучение на диалоге

> Навык: извлечение знаний из коммуникации.

## Зачем

Диалог — основной источник знаний системы. Без моста знания извлекаются только из технических ошибок. С мостом — каждая коррекция, уточнение, аналогия собеседника становится потенциальным знанием.

**Ценность:** Коммуникативные знания (intent gaps, decision patterns, satisfaction signals) — отдельный класс, недоступный через технический анализ.

## Цикл

```
L3 (Communication)          L2 (Knowledge)               L3 (Communication)
┌──────────────┐            ┌──────────────┐             ┌──────────────┐
│ Диалог:      │──сигнал──→ │ Новый кейс:  │──правило──→│ Адаптирован- │
│ коррекция,   │            │ communication│             │ ная          │
│ уточнение,   │            │ type         │             │ коммуникация │
│ аналогия     │            │              │             │              │
└──────────────┘            └──────────────┘             └──────────────┘
       ↑                                                        │
       └──────── меньше коррекций → лучше диалог ───────────────┘
```

## Что даёт

| Без моста | С мостом |
|-----------|----------|
| Знания только из ошибок | Знания из каждого взаимодействия |
| Коммуникативные ошибки повторяются | Коммуникативные паттерны фиксируются |
| Модель собеседника не обновляется | Interlocutor model растёт |

## Реализация

Полностью реализован через:
1. **`/learn communication`** — быстрый захват коммуникативного знания
2. **`/retro`** — тип `communication` для глубокого анализа intent gaps
3. **`session-collector.sh`** — напоминание о незафиксированных уроках
4. **META.md** — коммуникативные знания как отдельный source type
