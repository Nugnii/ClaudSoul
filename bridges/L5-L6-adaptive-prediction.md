# Мост L5↔L6: Адаптивное предсказание

> Навык: предсказания самоулучшаются через метаанализ.

## Зачем

Без этого моста предсказания L6 не получают обратной связи о своём качестве. L5 (метакогниция) имеет метрики, но не знает, как их применить к предсказаниям. С мостом — ошибки предсказаний анализируются мета-когнитивно, и методология адаптируется.

**Ценность:** Замкнутый цикл: predict → verify → analyze WHY wrong → adjust model → predict better. Без этого цикл обрывается на "verify" и не доходит до "adjust".

## Цикл

```
L6 (Prediction)             L5 (Meta-Cognition)          L6 (Prediction)
┌──────────────┐            ┌──────────────┐             ┌──────────────┐
│ Предсказание │──промах──→ │ Анализ: "все │──insight──→│ Адаптирован- │
│ + результат  │            │ промахи в    │             │ ная модель   │
│              │            │ ситуации X"  │             │              │
└──────────────┘            └──────────────┘             └──────────────┘
       ↑                                                        │
       └──────── лучшие предсказания → новые данные ────────────┘
```

## Что даёт

| Без моста | С мостом |
|-----------|----------|
| Промахи фиксируются, но не анализируются | Промахи анализируются → выявляются паттерны |
| Одинаковый подход ко всем предсказаниям | Адаптация подхода под тип ситуации |
| Manual tuning (через /retro) | Автоматический feedback loop |

## Реализация

1. **В metrics-collector:** при каждой верификации предсказания — записывать `{predicted, actual, accuracy, context_type}`
2. **В /knowledge-audit:** анализ: "предсказания по теме X работают, по теме Y — нет. Гипотеза: [...]"
3. **В knowledge-activator:** если prediction accuracy < 40% для текущего context_type → инжектировать "⚠️ Предсказания ненадёжны в контексте [X] — использовать режим silent prep, не gentle suggestion"
4. **Связь с L4↔L5:** калибровка (L4↔L5) даёт данные, адаптация (L5↔L6) меняет поведение
