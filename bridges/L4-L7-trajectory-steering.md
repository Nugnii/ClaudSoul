# Мост L4↔L7: Управление траекторией

> Навык: совместно управлять тем, КУДА движется мышление.

## Зачем

Без этого моста траектория — наблюдение за собеседником ("куда он движется?"). С мостом — траектория становится СОВМЕСТНОЙ: оба участника влияют на направление. Со-мышление порождает pivots (повороты), которых не было бы ни у кого в одиночку.

**Ценность:** Генеративность. Самые ценные идеи ClaudSoul (inter-layer bridges, проактивный intensity, "если знал — зачем делал?") родились как trajectory pivots в со-мышлении.


## Что даёт

| Без моста | С мостом |
|-----------|----------|
| Траектория = наблюдение | Траектория = совместное управление |
| Pivots случайны | Pivots осознаны и отслеживаются |
| Агент следует за собеседником | Агент со-управляет направлением |

## Реализация

1. **В SESSION.md Trajectory:** при записи pivot — отмечать `origin: co-cognition` если pivot родился из совместного обсуждения
2. **В /learn:** если кейс порождён trajectory pivot → `trigger: trajectory_pivot`
3. **В метриках:** track pivot_count_per_session, pivot_to_insight_ratio (какая доля pivots привела к ценным знаниям)
4. **В правилах:** при со-мышлении — активнее предлагать pivots (gentle suggestion), не только следовать
