# Мост L4↔L6: Готовность к следующему запросу

> Навык: предсказание следующего шага по траектории.

## Зачем

Траектория без предсказания = карта без компаса. Знаешь где был, не знаешь куда идёшь. Предсказание без траектории = угадывание. С мостом — траектория питает предсказание контекстом, предсказание задаёт вектор для траектории.

**Ценность:** Три режима предсказания (silent prep, gentle suggestion, proactive action) работают только при надёжной траектории. Без траектории = гадание.

## Цикл

```
L4 (Trajectory)             L6 (Prediction)              L4 (Trajectory)
┌──────────────┐            ┌──────────────┐             ┌──────────────┐
│ Траектория:  │──вектор──→ │ Предсказание:│──проверка─→│ Обновлённая  │
│ точки,       │            │ silent prep, │             │ траектория:  │
│ гипотеза,    │            │ gentle sugg.,│             │ match/miss   │
│ confidence   │            │ proactive    │             │ корректирует │
└──────────────┘            └──────────────┘             └──────────────┘
       ↑                                                        │
       └──────── верифицированное предсказание → лучше гипотеза ┘
```

## Что даёт

| Без моста | С мостом |
|-----------|----------|
| Предсказания случайны | Предсказания основаны на наблюдаемом тренде |
| Траектория = пассивное наблюдение | Траектория → активная подготовка |
| Нет обратной связи | Match/miss корректируют обе системы |

## Реализация

Неявно работает через:
1. **Prediction log в SESSION.md** — таблица предсказаний с верификацией
2. **Три режима** в CLAUDE.md — confidence порог определяет действие
3. **Верификация** — каждое новое сообщение проверяется против предсказания

### Для полной реализации нужно:
- Автоматическое извлечение вектора из 3+ точек (сейчас ручное)
- Статистика accuracy по типам траекторий (linear, pivoting, deepening)
- Адаптация confidence порогов: если accuracy по типу < 40% → повысить порог
