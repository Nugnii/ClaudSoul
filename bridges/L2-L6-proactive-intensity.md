# Мост L2↔L6: Проактивный intensity

> Навык: предсказание ошибки до действия. "Если знал — зачем делал?"

## Цикл

```
L2 (Knowledge)              L6 (Prediction)            Действие             L2 (Knowledge)
┌──────────────┐            ┌──────────────┐           ┌──────────┐         ┌──────────────┐
│ Совпадение   │──запрос──→ │ predicted    │──решение→ │ Действие │──факт→ │ actual       │
│ контекста    │            │ intensity    │           │ или блок │        │ intensity    │
│ (якоря)      │            │ = 0..5      │           │          │        │ сравнение    │
└──────────────┘            └──────────────┘           └──────────┘         └──────────────┘
       ↑                                                                          │
       └──────────────────── reinforce / contradict ──────────────────────────────┘
```

## Инверсия intensity=0

| predicted_intensity | outcome=success | outcome=error |
|---------------------|-----------------|---------------|
| 0 (ожидаемо) | Штатная работа | **Самая грубая ошибка**: знал → не предотвратил |
| 1-2 (предвидимо) | Хорошо | Ошибка с предупреждениями |
| 3-5 (неожиданно) | Удача/интуиция | Объективно сложный случай |

## Три режима

| predicted_intensity | Действие |
|---------------------|----------|
| 0 | **Блок**: не делать, предложить альтернативу |
| 1-2 | **Предупреждение**: озвучить риск, запросить подтверждение |
| 3-5 или N/A | **Осторожность**: действовать, логировать предсказание |

## Связь с конструктивным несогласием (⚡)

Конструктивное несогласие = частный случай (predicted_intensity=0, confidence≥4).
Проактивный intensity — обобщение: количественный механизм вместо качественного.
