# Мост L2↔L5: Самоочищение базы знаний

> Навык: рефлексия над качеством собственных знаний.

## Зачем

База знаний деградирует без контроля: устаревшие кейсы, ложные паттерны, непромоутированные знания. Без моста L5 (метакогниция) не знает, ЧТО мониторить. Без моста L2 (знания) не знает, что нуждается в ревью.

**Ценность:** Знания = капитал. Аудит = инвентаризация. Без инвентаризации капитал обесценивается незаметно.

## Цикл

```
L2 (Knowledge)              L5 (Meta-Cognition)          L2 (Knowledge)
┌──────────────┐            ┌──────────────┐             ┌──────────────┐
│ База знаний: │──метрики─→ │ Аудит:       │──действие─→│ Очищенная    │
│ кейсы,       │            │ decay,       │             │ база:        │
│ паттерны,    │            │ промоушен,   │             │ deprecated,  │
│ принципы     │            │ противоречия │             │ promoted,    │
│              │            │              │             │ reviewed     │
└──────────────┘            └──────────────┘             └──────────────┘
       ↑                                                        │
       └──────── чище база → точнее метрики ────────────────────┘
```

## Что даёт

| Без моста | С мостом |
|-----------|----------|
| Знания накапливаются без ревью | FSRS decay flagging устаревших |
| Паттерны не промоутируются | Автоматическое выявление кандидатов на промоушен |
| Противоречия не выявляются | Система обнаруживает и разрешает конфликты |

## Реализация

Полностью реализован через:
1. **`/knowledge-audit`** — полный аудит базы знаний: FSRS decay, промоушен, противоречия, пробелы
2. **`metrics-collector`** в knowledge-activator — depth, freshness, contradiction ratio, hit_rate
3. **Автосканер (launchd)** — периодический read-only анализ каждые 4ч
4. **knowledge-activator.sh** — инжект предупреждений о weakened/stale знаниях
