# Complexity Gate — Критерии запуска Skill Forge

## Зачем

Skill Forge — тяжёлый процесс (ресёрч, синтез, создание файлов). Запускать его для тривиальных задач — waste. Gate отсекает простые задачи до начала ресёрча.

## Четыре критерия

| # | Критерий | Вопрос | Да = +1 |
|---|----------|--------|---------|
| 1 | **Шаги** | Нужно ≥ 5 шагов для решения? | Многошаговая задача |
| 2 | **Повторяемость** | Эта задача может встретиться снова? | Скилл окупится |
| 3 | **Экспертиза** | Нужны знания за пределами текущего контекста? | Ресёрч необходим |
| 4 | **Покрытие** | Ни один существующий скилл не покрывает > 50%? | Нет готового решения |

## Решение

| Баллы | Действие |
|-------|----------|
| 0-1 | Решить напрямую. Скилл не нужен |
| 2 | На грани. Если пользователь просит — создать. Если агент — решить напрямую |
| 3-4 | Forge. Создать скилл |

## Примеры

**Forge (3+):**
- "Настрой мониторинг Kubernetes кластера" — 10+ шагов, повторяемо, нужна экспертиза, нет скилла
- "Сделай аудит безопасности Docker-образов" — многошагово, повторяемо, экспертиза, partial coverage

**НЕ Forge (0-1):**
- "Переименуй переменную" — 1 шаг, не повторяемо
- "Запусти тесты" — 1 шаг, есть инструмент
- "Добавь import" — тривиально

**Граница (2):**
- "Сгенерируй миграцию базы данных" — несколько шагов, повторяемо, но экспертиза не нужна и есть инструменты → решить напрямую
- Но если пользователь говорит "сделай скилл для миграций" → Forge (пользователь решил за gate)
