## Чувствительность (положительный класс)

Формы провайдеров, значения синтетические, структура из мира:

| форма | результат |
|---|---|
| AWS Access Key ID | ✓ `aws-access-token` |
| GitHub PAT (`ghp_`) | ✓ `github-pat` |
| GitHub fine-grained (`github_pat_`) | ✓ `github-fine-grained-pat` |
| OpenAI (`sk-proj-`) | ✓ `openai-api-key` |
| Anthropic (`sk-ant-api03-`) | ✓ `anthropic-api-key` — **правило своё**, в дефолте 8.30.1 отсутствует |
| Slack bot (`xoxb-`) | ✓ `slack-bot-token` |
| Stripe (`sk_live_`) | ✓ `stripe-access-token` |
| RSA private key | ✓ `private-key` (тело от ~3 строк) |

## Чего замер НЕ покрывает — называется, чтобы не считалось проверенным

* Замер сделан на ЧЕТЫРЁХ деревьях. Это не «ноль ложных вообще», а ноль на них.
* Положительный класс — синтетические значения. Настоящих ключей в замере нет и
  быть не должно.
* Форма фикстуры решает исход: за постройку четыре раза подряд низкоэнтропийная или
  неверная по алфавиту строка давала ложный вывод «инструмент не ловит». Всякое
  будущее расширение проверять формой ИЗ МИРА, иначе меряется фикстура, а не детектор
  (`pattern-fixture-form-not-taken-from-the-world`).
* Порог пересматривать, если ложные появятся: правило уровня 4 с ложными
  срабатываниями обязано вернуться на уровень подсказки.
